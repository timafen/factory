# Спецификация: общий учёт расхода Codex

## Цель и границы

Счётчик денег читает `rollout-*.jsonl` всех локальных профилей Codex, включает
расчётную API-стоимость в общий дневной предохранитель и показывает общий итог
на экране обзора. До появления надёжной связи журнала с `attempt_id` расход
Codex не приписывается отдельной задаче и не участвует в её личном потолке.
Стоимость подписки между задачами не распределяется.

## Контракт

- Из `event_msg/token_count` считаются входные, чтения и записи кэша, выходные
  токены. `last_token_usage` суммируется, а накопительный `total_token_usage`
  используется как дельта, чтобы повторные итоги не удваивали расход. Сохранённый
  накопительный итог обновляется и при наличии `last_token_usage`.
- Модель берётся из `turn_context`. Цена применяется только при точном
  совпадении имени с версионированной таблицей standard API pricing на
  2026-08-09: `gpt-5.6-sol`, `gpt-5.6-terra`, `gpt-5.6-luna`.
- При неизвестной модели токены остаются видимыми, а стоимость всего показанного
  периода отмечается как «стоимость не определена»; ноль и цена похожей модели
  не подставляются.
- Для контекста свыше 272K применяются множители GPT-5.6: 2x для входа и
  1.5x для выхода; запись кэша стоит 1.25x от входа. Если rollout не сообщает
  `cache_write_tokens`, интерфейс прямо называет сумму базовой оценкой.
- Общая известная стоимость Codex входит в дневной денежный предохранитель.
  В обзоре она складывается с существующей оценкой Claude, а токены Codex
  подписаны как общий итог, не как расход конкретной задачи.

## Вне области

- Атрибуция Codex к задаче до сохранения явной связи `attempt_id` ↔ session id.
- Расчёт фактической стоимости подписок или распределение абонентской платы.
- Изменение индивидуального потолка задачи и формата журналов Codex.

## Проверка

ГОТОВО-КОГДА: файл pilot/pilot.py
ГОТОВО-КОГДА: файл pilot/test_pilot.py
ГОТОВО-КОГДА: файл web/src/Overview.tsx
ГОТОВО-КОГДА: файл web/src/Overview.test.ts
ГОТОВО-КОГДА: команда python3 -m unittest pilot.test_pilot.CodexUsageTests
ГОТОВО-КОГДА: команда cd web && npm test -- --run src/Overview.test.ts

Целевые тесты проверяют чтение и цену записи кэша, тариф длинного контекста,
смешанную последовательность последних и накопительных значений, неизвестную
модель, включение известной стоимости в дневной итог и честную надпись в интерфейсе.
