# Аудит возможности восстановления повреждённой кириллицы

## Решение

До отдельного решения владельца данные не восстанавливаются. Поставка даёт
только офлайн-инвентаризацию согласованного снимка SQLite и указанных Git-коммитов.
Для сопоставления оператор передаёт JSON-экспорт из внешних первоисточников.
Команда не обращается к сети, не изменяет базу или Git и не печатает исследуемые
тексты.

## Интерфейс

```text
go run ./cmd/factory-audit-cyrillic \
  --database /path/to/factory.snapshot.sqlite3 \
  --sources /path/to/reviewed-sources.json
```

Файл первоисточников имеет версионированную форму:

```json
{
  "schema_version": 1,
  "tasks": [
    {"task_id":"...", "source_kind":"github_issue", "source_id":"owner/repo#1", "title":"исходный текст"}
  ],
  "commits": [
    {"repository_id":"...", "repository_path":"/read-only/clone", "revision":"полный SHA", "source_kind":"reviewed_export", "source_id":"...", "subject":"исходный текст"}
  ]
}
```

`title` и `subject` допустимы только во входном файле. JSON-отчёт содержит
идентификаторы, число `?` и один из статусов `recoverable`, `exact`, `conflict`
или `missing_source`. `recoverable` означает только проверяемое посимвольное
совпадение: каждый `?` в повреждённом тексте соответствует одному символу
первоисточника, а остальные символы совпадают. Это не разрешение на запись.

## Критерии приёмки

- SQLite открывается как `mode=ro&immutable=1`; инвентаризируются только строки
  `tasks.title`, содержащие `?`.
- Git используется только через `git show`; рассматриваются только явно
  перечисленные репозиторий и полный commit SHA.
- Внешний текст сопоставляется с записью, а неоднозначный или отсутствующий
  источник честно помечается и не считается восстановимым.
- stdout содержит только JSON без исходных или повреждённых текстов.
- байты снимка SQLite и состояние Git после команды остаются неизменными.
- повреждение не исправляется, история Git не переписывается, сеть не нужна.

## Проверка

```text
go test ./internal/cyrillicaudit ./cmd/factory-audit-cyrillic -count=1
go build ./cmd/factory-audit-cyrillic
```

## Вне объёма

- Автоматическое восстановление строк SQLite.
- Amend, rebase, force-push или любое иное изменение Git.
- Автоматическое извлечение первоисточников из GitHub или других сетевых систем.
- Доказательство исходного символа по одному `?` без независимого источника.
