# Настройки: выбор групп уведомлений на телефон

## Контракт

Экран Settings показывает фиксированный список из пяти групп уведомлений и сохраняет выбор в `notify_groups`. Подписи интерфейса русские, ключи API — `questions`, `stuck`, `money`, `done`, `routine`.

Источник правды — `NOTIFY_GROUPS` и `NOTIFY_DEFAULTS` в `/opt/factory-data/pilot/pilot.py`. При добавлении группы в пилоте этот список и UI нужно обновить вместе. При отсутствующем или пустом значении включены все группы, кроме `routine`.

## Критерии приёмки

- На экране всегда видны все пять групп независимо от текущего конфига.
- Текущее состояние переключателей берётся из `notify_groups`, отсутствующие ключи — из `NOTIFY_DEFAULTS`.
- Сохранение отправляет пять канонических английских ключей без потери остальных настроек.

## Вне задачи

Изменение маршрутизации и публикации уведомлений в пилоте, создание новых групп и перевод остальных полей Settings.
