# Серверный браузер для агентов и «Диалога»

## Решение

Factory использует установленный на сервере Chromium в headless-режиме. Один
runner обслуживает HTTP API «Диалога» и CLI `factory-worker browser`, доступную
агентам. Путь берётся из `FACTORY_BROWSER_EXECUTABLE`, системного `PATH` либо из
кэша Chromium, установленного Playwright; серверная установка описана скриптом
`ops/install-server-browser.sh`.

Chromium запускается от непривилегированного пользователя Factory со штатной
системной песочницей: отключающие sandbox флаги запрещены. Его сеть дополнительно
закрыта локальным allowlist-прокси; системные права процесса не расширяются.

## Граница доступа

Разрешён только origin `https://staging-automation.tarser.net` и любые пути на
нём. Исходный URL проверяется до запуска Chromium. Весь трафик Chromium идёт
через локальный CONNECT-прокси, который допускает только этот host и порт 443,
отключён QUIC. Поэтому переход или HTTP-редирект на production, старые стенды,
внешний сайт, localhost или внутренний IP не получает соединение. Сам стенд
также резолвится один раз и соединение устанавливается только с публичным IP;
CGNAT, документационные и остальные специальные IPv4/IPv6-сети запрещены.

## Контракты

- CLI: `factory-worker browser -output <png> <url>`; таймаут по умолчанию 45 с,
  файл создаётся с правами 0600.
- API: `POST /api/v1/browser/capture`, JSON `{ "url": "..." }`; успешный ответ
  содержит канонический URL, `image/png` и base64-данные. Тело ограничено 4 KiB,
  одновременно выполняется не более одного снимка, занятый слот возвращает 429.
- UI: на `/dialog` оператор вводит путь утверждённого стенда, получает снимок и
  отправляет его выбранной модели как обычное вложение.
- Ошибочный origin возвращает `browser_url_not_allowed`, отсутствие/сбой
  Chromium — `browser_unavailable` без раскрытия внутренней диагностики.

## Проверка

Unit-тесты покрывают точный allowlist, запрет CGNAT и специальных IPv4/IPv6,
прокси для внешних CONNECT, запуск Chromium с sandbox только через прокси,
ограничения размера и параллелизма API до запуска runner и прикрепление
серверного снимка в «Диалоге». Production-сборка UI фиксируется в `web/dist`.

## Вне области

Production и прежние стенды, произвольный интернет, localhost, внутренние IP,
интерактивное управление вкладкой, хранение истории снимков и обход авторизации.
