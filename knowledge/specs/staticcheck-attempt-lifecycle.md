# Спецификация: актуальные доказательства CARD-0126

## Цель и влияние на владельца

Закрепить актуальное, воспроизводимое доказательство, что исправление
ложного `SA4000` в lifecycle-тесте worker остаётся в текущей базе. Владельцу
не нужно принимать старые логи за подтверждение новой версии: карточка явно
привязывает результат к существующему implementation commit и к команде,
которую можно повторить с кодом выхода 0. Product code, UI и поведение lease
renewal не меняются.

## Технический подход и реальные файлы

Уже поставленное исправление находится в
`internal/worker/attempt_lifecycle_test.go`: два независимых вызова
`leaseRenewalDelay` сохраняются в `wantStableDelay` и `gotStableDelay`, после
чего сравниваются между собой. Это заменяет самосравнение, на которое жалился
staticcheck (`SA4000`). Команда `just staticcheck` в `Justfile` проверяет
`SA*,U1000` для `./...`.

Эта поставка меняет только документы:

- `knowledge/specs/staticcheck-attempt-lifecycle.md`;
- `knowledge/cards/CARD-0126-staticcheck-attempt-lifecycle.md`.

## Последовательный план

1. Сверить тест lifecycle и правило `just staticcheck` с текущим кодом.
2. Запустить целевой `go test` для проверок lease renewal.
3. Запустить полный `just staticcheck` и записать только его фактический
   результат в карточке.
4. Не запускать и не выдавать browser suite за доказательство: он не связан с
   изменением теста worker.

## Критерии приёмки

- В lifecycle-тесте нет самосравнения, вызывающего `SA4000`.
- Одинаковый attempt ID даёт одинаковую фазу продления lease; проверка бюджета
  и распределения фаз остаётся в тесте.
- `go test ./internal/worker -run '^TestLeaseRenewal'` и `just staticcheck`
  завершаются с кодом 0.
- Карточка содержит полный SHA implementation commit, который существует в
  ветке и меняет файл вне `knowledge/cards/`.
- В diff этой документационной поставки нет product code и UI.

## Тест-план

- Целевой: `go test ./internal/worker -run '^TestLeaseRenewal'`.
- Обязательный: `just staticcheck`.
- Проверка области: `git diff --name-only origin/main...HEAD` должна содержать
  только эту спецификацию и карточку CARD-0126.

## Результат реализации

На ветке поставки выполнены обе проверки из тест-плана: целевой lifecycle-тест
worker и проектный `staticcheck` завершились с кодом 0. Доказательство
сохраняется в этой спецификации, а карточка CARD-0126 ссылается на отдельный
commit реализации этой записи.

## Риски и решения

- Старое доказательство может относиться к другой ревизии — указывать полный
  SHA реализации и заново запускать обязательную команду.
- Замена assertion могла бы ослабить тест — сохранять два вызова и проверять
  тот же инвариант детерминированности.
- Смежные browser-падения могут исказить вывод — не включать browser suite в
  доказательство этой Go-тестовой правки.
