# Автопочинка не считает один запуск дважды

## Цель

Если полный список задач повторяет один активный запуск, Фабрика распознаёт его
по ID как один запуск и не останавливает безопасную автопочинку сообщением
«найдено активных запусков — 2».

## Контракт безопасности

- Активные записи одной работы с одинаковым непустым ID считаются одним запуском.
- Активные записи с разными ID остаются разными запусками и запрещают отмену.
- Записи без ID не объединяются: недостаток идентичности не должен разрешить
  необратимое действие.
- Сохраняются полный курсорный обход, проверка состояния кандидата, адресная
  отмена, обязательные данные продолжения и идемпотентные состояния ремонта.

## Критерии приёмки

1. Две активные записи с ID кандидата приводят к одной адресной отмене, ожиданию
   терминального состояния и одному продолжению на прежней ветке.
2. Два разных активных ID по-прежнему дают отказ «найдено активных запусков — 2»
   без вызова отмены, в том числе если второй ID пришёл на следующей странице.
3. Все 17 сценариев `DiagnosisRepairTests` проходят.

## Проверка

- `python3 -m unittest pilot.test_pilot.DiagnosisRepairTests`
- `python3 -m py_compile pilot/pilot.py pilot/test_pilot.py`
- `git diff --check`

## Вне области

Изменение порогов диагностики, отмена нескольких запусков, новые API, миграции
и повторный автоматический ремонт.
