# Санитар retained worktree только для offline-воркеров

## Цель

Локально подтверждённая очистка retained worktree должна выполняться лишь для
неактивной offline-регистрации. Online-воркер может продолжать работу, поэтому
санитар не должен останавливать его из-за сохранённой записи.

## Реализация

В `ops/factory-janitor.sh` отбор перед остановкой службы требует одновременно:

- `online == false`;
- `active_count == 0`;
- непустой `retained_worktrees`.

Существующее точечное подтверждение сохраняется: санитар отправляет только
локально подтверждённые снимки, а защищённый loopback-маршрут удаляет только
точно совпадающие записи.

## Проверки

`ops/test-factory-janitor.sh` моделирует допускаемый offline `claude-haiku`,
active offline-воркер, online-воркер и offline-воркер без retained-записей.
Проверка подтверждает очистку только первого случая. Проверка HTTP-маршрута
подтверждает, что forwarded-запрос остаётся запрещённым.
