# Спецификация: повторный Review CARD-0135

## Цель и влияние на владельца

Предложение закрывается как дубликат CARD-0135. Новая реализация и новая карточка не нужны: владелец получает независимую проверяемую передачу уже реализованных Pilot-ворот на повторный Review. В выпуске полный `pilot.test_pilot` должен завершаться до сборки и установки; ошибка Pilot должна останавливать выпуск и не перезапускать службы.

## Технический подход и реальные файлы

Истина для Review — опубликованная ветка `origin/factory/ac965c5a-61a-17593895-e52`, implementation commit `1141c215d3d9f26bf26ed6b3e0a6e839def28249`, передача на Review — `712566a1`. Коммит `a322676d` не относится к реализации.

Реальные файлы реализации: `ops/fx-factory-release` добавляет доверенный Python executable, отдельную параллельную группу Pilot и корректное ожидание/остановку всех групп; `ops/test-fx-factory-release.sh` расширяет герметичный полигон успешным и падающим Pilot-сценарием; `pilot/test_pilot.py` — полный набор, запускаемый воротами.

## Последовательный план

1. Сверить candidate `712566a1` с remote default `main` по зафиксированным SHA.
2. Проверить diff и чтением подтвердить порядок Pilot до UI/Go build, отдельный лог и безопасную остановку соседних групп.
3. Передать существующую CARD-0135 на независимый повторный Review; не создавать карточку и не менять продуктовый код.
4. Зафиксировать только эту спецификацию, перебазировать на свежий `origin/main`, проверить область diff и запушить ветку.

## Критерии приёмки

- карточка CARD-0135 остаётся единственной карточкой работы и имеет статус ожидания повторного Review;
- Pilot запускается отдельной доверенной группой до сборки/установки и имеет отдельный вывод;
- ненулевой результат Pilot останавливает UI/Go-группы, сборку, установку и перезапуск служб;
- оболочка release-скриптов и полигон покрывают успешный и падающий Pilot-сценарии;
- поставка этапа содержит только эту спецификацию.

## Тест-план

Для реализации Review: `python3 -m unittest pilot.test_pilot`; `bash ops/test-fx-factory-release.sh`; `bash -n ops/fx-factory-release ops/test-fx-factory-release.sh`; при интеграционной проверке — `just build`. На этом этапе тесты не запускаются повторно: спецификация проверяется чтением фактического diff и наличием зафиксированных результатов в CARD-0135.

## Риски и решения

- Повторная работа может случайно породить расходящуюся карточку — использовать только существующую CARD-0135.
- Проверка не того коммита исказит Review — считать источником истины `1141c215`; `a322676d` исключить.
- Кэшированный remote ref может быть устаревшим — перед сравнением получить remote HEAD и fetch свежего `main`.
- Полный набор может быть нестабилен вне области — отделять такие находки от критериев Pilot-ворот и фиксировать их отдельно.
