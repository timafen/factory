# Автоподбор верхней карточки Плана

Пилот сам запускает верхнюю карточку со статусом `planned`, когда в конвейере
занято меньше трёх уникальных работ. За один цикл запускается не более одной
карточки, поэтому порядок Плана остаётся источником приоритета.

Занятым слотом считается уникальная `[auto]`-работа, которая выполняется,
стоит в очереди или ждёт ответа владельца. Завершённые работы слот не занимают.
При создании действует общий `money_guard`: дневной предел всех задач и предел
одной работы нельзя обойти автоподбором.

Карточка стартует с первого настроенного этапа (`Triage`) и получает контекст:
название, «зачем», источник и прямое указание провести разбор готовности. Только
после успешного создания задачи карточка становится `in_work` и получает
`task_id`. Запись «Взял из Плана» относится к тихой группе `routine`.

Вне области: изменение экрана Плана, одновременный запуск нескольких карточек,
пагинация снимка задач свыше текущего лимита API.
