# CARD-0124 — Снимок базы без зависимости от HOME

Implementation commit: 99701704b37e8740db3fdbe38c0193917570da5c — snapshot SQLite создаётся владельцем базы в рабочем каталоге и затем переносится в поколение выпуска.

## Статус

Verified PASS — ожидает squash-слияния канонической ветки; текущая работа является точным дублем и не добавляет продуктовой реализации.

## Результат

`ops/fx-factory-release` вызывает `factory-server -database ... -backup ...` через рабочего пользователя, использует временный путь, проверяет standalone SQLite и переносит готовые файлы в staging с нужными правами. Это сохраняет выпуск работоспособным при запуске без унаследованного `HOME` и не меняет исходную базу.

## Проверки

- subprocess-тест проверяет четыре формы флагов без `HOME`.
- Проверены самостоятельность snapshot и неизменность источника.
- Каноническая карточка имела статус Verified PASS; повторный pipeline не запускается.
