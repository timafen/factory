# CARD-0090 — Цена дублей, отмен и незавершённых конвейеров

Implementation commit: 0ec9dd9e3f27a4ef0c5ce8a4503f1ba4d9ef0622 — текущая кодовая база контрольного конвейера, для которой зафиксирован контракт реализации.

## Статус

Specification: подготовлена проверяемая спецификация; продуктовый код и UI на
этом этапе не изменяются.

## Решение владельца

Ввести явные `owner_cancel`, `system_duplicate`, `review_return`,
`verify_return`, `undelivered`; связывать расходы с `work_id`; новые отмены
сохранять с причиной; исторические записи без доказательств показывать как
`unknown` и считать отдельно.

## Контекст и границы

Текущие метрики считают состояния execution и не связывают Codex-расход с
работой. API отмены принимает пустое тело, а эвристика по названиям смешивает
технические отмены с провалом. Реализация должна затронуть миграцию, модели,
control-plane state/http/metrics и целевые тесты; UI в этой карточке не входит.

## Следующий этап

Реализовать спецификацию из
`knowledge/specs/2026-08-12-metrics-outcome-cost-attribution.md`, затем
проверить миграцию на старой БД, HTTP-контракт отмены, идемпотентность расходов
и независимые totals двух `work_id`.
