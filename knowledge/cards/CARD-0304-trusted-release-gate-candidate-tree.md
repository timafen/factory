## LOG

### 2026-08-15 — Specification

Определены два допустимых источника fixture: Git checkout рядом со скриптом для
прямого запуска и `PWD` clone кандидата для извлечённого trusted gate. Закреплены
fail-closed поведение, абсолютный системный Git, отсутствие второй полной копии
дерева и сохранение handshake/race-защиты.

НАХОДКА: полный целевой полигон на свежем `main` два раза завершился одинаково:
`FAIL: timed out waiting for .../signal-HUP-1/ui-running`. Это поздняя
signal-проверка существующего полигона, не изменение документационного этапа;
Implement + Test должен получить код 0 обязательной команды перед передачей.
