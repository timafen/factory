Implementation commit: 6ecf7f81bbf07111a46d244eafb5c97e065fb023 — находки из любого завершённого отчёта сохраняются в Плане, а сбой авторазбора остаётся техническим повтором.

## Статус

Specified. Карточка описывает текущую работу спецификации; реализация
зафиксирована отдельным предшествующим коммитом.

## Результат для владельца

Технические находки из отчётов попадают в План сами. Владелец получает только
вопросы, в которых действительно требуется его решение.

- Реализация: `pilot/pilot.py`, `pilot/test_pilot.py`.
- Экран Plan и control-plane API не требуют изменений.
