# CARD-0050 — Выпуск показывает человеческое название изменения

## Почему

После обычного merge через GitHub заголовком коммита становится служебная строка
`Merge pull request ...`. Она попадала в сведения о выпуске вместо смысла
изменения и нарушала правило человекочитаемых сообщений владельцу.

## Готово, когда

- для merge-коммита выпуск берёт название PR из тела коммита;
- служебный номер PR в конце названия не показывается;
- обычный заголовок коммита остаётся без изменений;
- пустое название имеет понятный запасной текст;
- регрессионный тест запрещает служебную строку, номер PR и голый хеш в выводе.

## Проверено

- `bash ops/test-fx-factory-release.sh`
- `git diff --check`
