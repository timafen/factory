# CARD-0155 — Ежедневный PDF с визуальными результатами работы

## Статус

- Этап: Specification; продуктовый код в этой ветке не меняется.
- Спецификация: `knowledge/specs/daily-visual-report-pdf.md`.
- Владелец получает ежедневный скачиваемый PDF с метриками конвейера и честными
  парами экранов «до/после».
- Следующее действие: реализовать durable capture/report pipeline и заменить
  верхнюю строку SHA отдельным implementation-коммитом этой работы.

## Зафиксированное решение владельца

У каждой визуальной работы обязателен собственный target: URL, состояние и
viewport. «Обзор» не является запасным экраном и используется только для работы
над ним. Factory сохраняет «до» до начала изменений и снимает «после» при тех же
условиях. Отсутствующее «до» обозначается прямо и никогда не подменяется.

## Граница работы

- Отдельные durable visual captures и daily reports, не входные task attachments.
- Снимок до первого claim, снимок после ручной работы либо успешного `Verify`.
- Один отчёт за календарный день выбранной timezone, инфографика и сравнение
  операционных метрик Factory с предыдущим днём.
- Русскоязычный экран списка/скачивания и обязательные visual target fields в
  постановке задачи.
- Не входят: извлечение KPI из произвольного сайта, сценарии кликов для сложного
  состояния, отправка PDF почтой/в мессенджер и политика автоудаления.

## Критерий результата

До допуска агента Factory либо сохраняет проверенный «до», либо долговечно
фиксирует причину его отсутствия. После финальной стадии использует тот же
target. Утренний PDF показывает эти факты без случайных эталонов, а повторный
запуск или рестарт не создаёт дубликат отчёта и пары.

## Проверка реализации

Обязательная регрессия
`TestDailyVisualReportKeepsMissingBeforeHonest` создаёт visual work с неуспешным
before capture, допускает работу после terminal failure, завершает target stage
и собирает PDF model. В модели обязаны остаться missing-placeholder и исходная
причина; ни один другой PNG не может занять позицию «до».

Команда:
`sh -c "grep -q 'func TestDailyVisualReportKeepsMissingBeforeHonest' internal/controlplane/reports_test.go && go test ./internal/controlplane -run '^TestDailyVisualReportKeepsMissingBeforeHonest$'"`.
Так проверка не может ложно пройти, если Go не нашёл именованный
тест.
