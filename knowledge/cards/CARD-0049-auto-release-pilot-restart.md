# CARD-0049 — Автовыпуск переживает перезапуск Пилота

## Почему

Автовыпуск запускается как дочерний процесс `factory-pilot.service`. Установка
нового мозга раньше немедленно перезапускала эту службу. `systemd` вместе с
Пилотом останавливал и сам выпуск: бинарные файлы уже могли быть заменены, но
сведения о версии, очистка и финальное подтверждение не выполнялись.

## Готово, когда

- установщик мозга умеет обновить файлы и проверить новый код через Intake,
  не перезапуская Пилот внутри незавершённого выпуска;
- успешный выпуск ставит отдельный отложенный перезапуск Пилота только после
  проверки мозга и записи сведений о версии;
- неуспешная проверка мозга возвращает прежние файлы, не ставит отложенный
  перезапуск и откатывает пару сервер/воркер;
- обычный ручной запуск установщика мозга сохраняет прежнее немедленное
  поведение;
- регрессионные shell-тесты покрывают успех, откат и порядок операций.

## Проверено

- `bash ops/test-install-brain.sh`
- `bash ops/test-fx-factory-release.sh`
- `git diff --check`

Оба набора shell-тестов проходят локально; полный выпуск проверит те же ворота
на сервере перед установкой.
