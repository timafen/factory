# CARD-0094 — Утечка mock-объекта в production dashboard

Implementation commit: e097fb1026c0d0991cc17eb891fdcd58c9ac0602 — введено честное отображение отсутствующих данных на обзоре; это исходный кодовый контекст для исправления mock-fallback.

## Контекст

`web/src/Overview.tsx` создаёт `Dash` пустым объектом до получения ответа.
При сбое production-запроса это маскирует отсутствие снимка как обычный
пустой dashboard.

## Решение

Заменить mock-fallback на явные состояния загрузки и ошибки, оставить
деградацию только для отсутствующих полей в успешном ответе, а повторную
загрузку сделать доступной владельцу.

## Область следующего этапа

- `web/src/Overview.tsx`
- `web/src/Overview.test.tsx`

## Проверка

`npm --prefix web test -- --run src/Overview.test.tsx` завершается с кодом 0
и включает сценарии loading, error и повторного успешного ответа dashboard.
