# CARD-0090: свежесть dashboard после рестарта

Implementation commit: отсутствует — этап Specification, продуктовый код намеренно не изменялся.

## Что должно измениться

После рестарта `factory-pilot` «Обзор» получает свежий полный снимок в первом
успешном цикле. При сбое сборки сохраняется последний валидный JSON, но возраст
и причина становятся видимыми владельцу; промежуточный или обрезанный файл не
отдаётся.

## Границы

В работе: `pilot/pilot.py`, его целевые тесты, чтение dashboard в
`internal/controlplane`, отображение свежести и тесты «Обзора». Не входят
новые продуктовые метрики, изменение компоновки UI, внешние команды на HTTP
запрос и исправления несвязанных ошибок.

## Проверка

Обязательна команда из спецификации
`knowledge/specs/overview-dashboard-freshness-after-pilot-restart.md`.
