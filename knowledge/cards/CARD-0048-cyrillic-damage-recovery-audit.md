## LOG

### 2026-08-10 — Specification

Восстановление запрещено без отдельного решения владельца. Контракт ограничен
офлайн-инвентаризацией согласованного SQLite snapshot и явно перечисленных
Git-коммитов. Исследуемые тексты допустимы во входном файле, но не в отчёте;
один `?` сам по себе не считается доказательством исходного символа.

### 2026-08-10 — Implement

Добавлена офлайн-команда `factory-audit-cyrillic`. SQLite открывается через
`mode=ro&immutable=1`, Git читается через `git show` с отключёнными optional
locks, а отчёт содержит только идентификаторы, счётчики и статусы сопоставления.
Регрессия подтверждает неизменность байтов snapshot и состояния Git, отсутствие
WAL/SHM и отсутствие обоих исследуемых текстов в JSON. Целевые тесты, полный
Go-набор, сборка команды, `go vet` и `git diff --check` прошли.

### 2026-08-10 — Implement

После REQUEST CHANGES вызов Git принудительно получил `GIT_NO_LAZY_FETCH=1` и
`GIT_NO_REPLACE_OBJECTS=1`. Новые тесты подтверждают, что отсутствующий объект
не скачивается из promisor remote и что `refs/replace` не подменяет заголовок.
Обе регрессии, полный набор из 13 Go-пакетов, сборка и целевой `go vet` прошли.
