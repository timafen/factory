# CARD-0097 — Два цикла ограничены десятью задачами в час

Implementation commit: ec50c36fb263dd8637d4820ee3a9d69be8ee13b2 — Pilot ждёт следующей допустимой попытки, а лимит проверен конкурентно.

## Статус

Specification — готова к Implement + Test.

## Суть работы

Два цикла Factory могут одновременно создавать продолжения. Суточный предел и
локальный снимок активных работ не дают общего почасового предохранителя, поэтому
следующий этап добавит единый атомарный предел: не более 10 новых
автоматических задач за скользящие 60 минут, idempotent replay без расхода
квоты и отложенный handoff в Pilot.

## Область

- `internal/controlplane/store.go` и новая миграция durable-почасового окна;
- `pilot/pilot.py` для defer без повторной постановки;
- целевые тесты control plane и Pilot;
- без изменений UI и продуктовых экранов.

## Проверки следующего этапа

- десять автоматических созданий проходят, одиннадцатое возвращает
  `hourly_task_cap`;
- две конкурентные транзакции не превышают предел;
- replay того же `request_key` не расходует квоту;
- после истечения 60 минут создаётся ровно один следующий этап;
- обязательная команда из спецификации завершается с кодом 0.

## Контекст передачи

Карточка продолжена из triage вместе с указанным коммитом реализации. На этапе
Specification зафиксированы реальные текущие точки в `CreateTask` и Pilot, а
также новая миграция после существующей `030_visual_report_claims.sql`.
